# Demonstração · Gestão de estoque para a Remo

Demonstração de um sistema de gestão de estoque para a **Remo Distribuidora de Alimentos Ltda.**,
desenvolvido pela **Wydan Solutions**: mapa do galpão com cada produto no seu lugar, estoque que baixa
sozinho a cada venda, lotes e validades, semáforo (crítico, baixo, OK), aviso por e-mail para pedir mais,
entrada de mercadoria, leitura de código de barras pela câmera, consultas, estatísticas e exportação para Excel.

- **Produtos, quantidades, preços, clientes, fornecedores e vendas são inventados** para a demonstração.
- Funciona por completo no navegador: não há servidor nem banco de dados.
- Senha da demonstração: `1234` (serve para os três usuários: Gerência, Depósito e Caixa).

Cada pessoa que abre a página trabalha com a sua própria cópia dos dados de exemplo, guardada só no seu navegador.
